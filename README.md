# Training-a-Multilayer-Perceptron-Model-using-Scikit-Learn
This lab trains a Multilayer Perceptron (MLP) model using Scikit-Learn to classify data. It includes data preprocessing, model training, and performance evaluation using accuracy and classification reports, showcasing foundational neural network techniques in Python.

# Overview
- This lab focuses on training a Multilayer Perceptron (MLP) classifier using the Scikit-Learn library. It walks through the complete process of loading data, preprocessing, training the MLP model, and evaluating its performance using common classification metrics.

# Goals
- Understand how to use MLPClassifier from Scikit-Learn
- Train and evaluate a neural network model on structured data
- Apply standard scaling and label encoding
- Analyze model performance using accuracy and classification reports

# Tools Used
- Python
- Jupyter Notebook
- Scikit-learn
- Pandas, Numpy
- mMatplotlib (for optional plotting)

# Key Findings
- The MLP model can achieve strong accuracy when properly scaled
- Hyperparameter tuning (number of hidden layers, solver type) significantly impacts performance
- Preprocessing, especially feature scaling, is critical for neural network training
